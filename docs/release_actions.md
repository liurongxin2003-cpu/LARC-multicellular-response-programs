1. Create the requested public repository under the author's GitHub account and add the complete contents of this archive, including licenses and metadata. Do not add the enclosing project folder, runtime, raw files, manuscripts or internal analysis outputs.
2. Commit/tag v1.1.0, then create a versioned release. Verify the public README, file manifest and downloaded archive.
3. In the author's Zenodo account, enable that repository under GitHub integration before creating the release, or create a software deposit from this exact ZIP. Review creators/licenses/third-party exclusions, publish, and verify the assigned version DOI and record files.
4. Record actual URLs/DOI in publication_state.json and rerun the final document synchronization. Do not replace an unresolved identifier with an invented link. GitHub/Zenodo account or integration steps require the actual account session; this file does not claim they have occurred.
